FASTEST FIX - One Command (Copy-Paste This)
================================================================================

If you're having PowerShell script issues, use this ONE command instead:

Copy the entire line below and paste into PowerShell:

python -m pip install --upgrade pip setuptools wheel && python -m pip install -r requirements.txt

That's it!

================================================================================
WHAT IT DOES
================================================================================

This single command:
1. Upgrades pip, setuptools, wheel
2. Installs all packages from requirements.txt
3. Uses binary wheels (no compilation needed)
4. Takes 2-3 minutes

================================================================================
STEP-BY-STEP FOR POWERSHELL
================================================================================

STEP 1: Make sure you're in the project directory
────────────────────────────────────────────────

cd D:\final\AircraftPredictiveMaintenance

STEP 2: Delete the old failed venv (optional but recommended)
────────────────────────────────────────────────────────────

Remove-Item -Recurse -Force venv

(This deletes the old broken environment)

STEP 3: Create fresh virtual environment
──────────────────────────────────────────

python -m venv venv

STEP 4: Activate it
────────────────────

.\venv\Scripts\Activate.ps1

You should see (venv) in your prompt

STEP 5: Install all packages (THE IMPORTANT PART)
──────────────────────────────────────────────────

python -m pip install --upgrade pip setuptools wheel && python -m pip install -r requirements.txt

Wait 2-3 minutes for completion

STEP 6: Verify installation worked
──────────────────────────────────

python -c "import pandas; import tensorflow; import streamlit; print('All packages installed!')"

Should print: "All packages installed!"

================================================================================
