================================================================================
KEY DIFFERENCES: PowerShell vs Command Prompt
================================================================================

Command Prompt (cmd.exe):
  setup.bat
  venv\Scripts\activate.bat

PowerShell:
  .\setup.bat                    ← Note the ".\" prefix
  .\venv\Scripts\Activate.ps1    ← Note the ".\" prefix AND .ps1 extension

Everything else is the same!

================================================================================
TROUBLESHOOTING FOR POWERSHELL
================================================================================

PROBLEM: "The term 'setup.bat' is not recognized"
SOLUTION: Use ".\setup.bat" (add the ".\" prefix)

PROBLEM: "cannot be loaded because running scripts is disabled"
SOLUTION: Run PowerShell as Administrator, then execute:
          Set-ExecutionPolicy -ExecutionPolicy RemoteSigned

PROBLEM: Still won't run?
SOLUTION: Use Command Prompt instead (press Win+R, type "cmd", Enter)

================================================================================
