=============================================================================
TROUBLESHOOTING
=============================================================================

PROBLEM: "Python not found"
SOLUTION:
- Install Python 3.10+ from https://www.python.org
- Important: Check "Add to PATH" during installation
- Restart command prompt

PROBLEM: setup.bat fails
SOLUTION:
- Delete venv folder: rmdir /S venv
- Retry: setup.bat

PROBLEM: "Models not found" when running dashboard
SOLUTION:
- Models need to be trained first
- Run: python training\train_all.py
- Wait for completion
- Then: streamlit run dashboard\app.py

PROBLEM: Training takes too long / Out of memory
SOLUTION:
- Edit: config\config.py
- Change: EPOCHS = 20 (was 50)
- Change: BATCH_SIZE = 64 (was 32)
- Retrain: python training\train_all.py

PROBLEM: Dashboard won't start
SOLUTION:
- Press Ctrl+C to stop current process
- Clear cache: rmdir .streamlit\cache
- Retry: streamlit run dashboard\app.py

PROBLEM: Files not found error
SOLUTION:
- Verify dataset files exist: dir data\engine\
- Check all 20 files are there
- Filenames must be exactly: FD001_train.txt, etc.
